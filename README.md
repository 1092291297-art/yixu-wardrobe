# 衣序 5.0

无需登录的中文个人衣橱，入口为根目录 `index.html`，适合直接部署到 GitHub Pages。

主要功能：

- 内搭、外搭、裤子、袜子、鞋子和配饰管理。
- 自动提取主色，并从文件名给出类别、层级、季节、保暖程度和风格建议。
- 衣物状态、资料完整度、穿着次数和最近穿着概览。
- 名称搜索、类别与状态筛选，以及按添加时间、穿着次数、最近穿着和名称排序。
- 场景、季节、体感温度、身体偏好和穿着轮换共同参与推荐。
- 收藏搭配、整套穿着记录、完整 JSON 备份与恢复。
- 单件快速穿着记录、复制单品和删除撤销。
- 精简的添加流程，裤装专属字段按类别显示，高级照片工具默认折叠。
- 多照片连续录入，逐件确认属性后自动进入下一张。
- 穿搭日历、整套与单件穿着记录、重复计数保护。
- PWA 安装清单、桌面图标和离线缓存，可添加到手机主屏幕。
- 备份时间记录与 30 天备份提醒。
- 洗衣篮、批量状态管理和手机底部快捷导航。
- 穿搭日历支持补记、修改、复制和删除。
- 单品存放位置、购买价格、穿着频率及每次穿着成本统计。

衣橱、照片和身体数据保存在访问者当前浏览器的 IndexedDB，不上传到 GitHub。清除网站数据会删除衣橱，建议定期备份。

可选 AI 使用 Transformers.js 3.8.1 和 `Xenova/clip-vit-base-patch32`。国内网络或设备不支持时仍可手动填写。
